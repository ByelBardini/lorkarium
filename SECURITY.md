# Política de segurança

## Versões suportadas

| Versão                                  | Recebe correções de segurança  |
| --------------------------------------- | ------------------------------ |
| A branch `main` (o que está no ar)      | Sim                            |
| A última release do app para Windows    | Sim                            |
| Releases anteriores do app para Windows | Não: o app se atualiza sozinho |

## Como relatar uma falha

**Não abra uma issue pública.** Relate em particular, por um destes canais:

- o botão **Report a vulnerability**, na aba [Security](https://github.com/ByelBardini/lorkarium/security/advisories/new) deste repositório;
- o e-mail **<privacidade@evolutivasistemas.com.br>**, o mesmo canal de segurança dos Termos de uso.

Informe, se puder:

- o que é a falha e o impacto que ela pode ter;
- os passos para reproduzir (endereço, requisição, conta de teste, versão do app);
- uma prova de conceito, se tiver;
- como você quer ser creditado, ou se prefere ficar anônimo.

## O que esperar

- Confirmamos o recebimento e respondemos em até **15 dias**.
- Avisamos quando a falha for corrigida e combinamos com você a data da divulgação.

## Divulgação responsável

As regras são as da [Política de uso aceitável](https://lorkarium.com.br/uso/) (seção 11):

- teste só o necessário para demonstrar a falha, de preferência com contas suas;
- não acesse, altere nem apague dados de outras pessoas;
- não degrade o serviço (nada de negação de serviço, spam ou engenharia social);
- não divulgue a falha antes de ela ser corrigida.

Quem segue estas regras não sofre nenhuma medida por ter encontrado e relatado a falha.
