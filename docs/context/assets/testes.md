Hub: [`../assets.md`](../assets.md).

- `server/test/integration/assets.spec.ts` (Postgres e SeaweedFS descartáveis, `app.inject()`): mestre e jogador enviam, leitura com os cabeçalhos, 3000 × 3000 → 1024 × 1024, Quelm não lê o de Vharn (e vice-versa), 401, não membro → `CAMPAIGN_NOT_FOUND`, GIF → 415, texto como PNG → 422, 20 MiB + 1 → 413, link para 127.0.0.1 → `LINK_BLOCKED` (a política real), `ftp:` → 400, o 21º envio → 429; GIF como token → **422** e SVG → 415; `purpose=condition`: 600 × 300 → 256 × 256, GIF → 422, espectador → 403 `FORBIDDEN`, Quelm não lê a de Vharn; `purpose=aura`: GIF de 3 quadros → 201 `image/gif` e o `GET` com `Content-Type: image/gif` e os 3 quadros, PNG 900 × 900 → 512 × 512, 121 quadros → 422, Quelm não lê a de Vharn. O GIF dos specs sai do `animatedGifOf(quadros, lado)` de `test/support/images.ts`.

- Unit `server/test/modules/assets/`: `asset-upload.bo.spec.ts` (`resizeFor` de cada finalidade, `animationFor` só na `aura`), `assets.mapper.spec.ts` e `assets.service.spec.ts` (a `condition` pede `{ 256, square }` no envio e no link; a `aura` pede `{ 512, animation }` no envio e no link, o `token` sem `animation`; `too-many-frames` → `UNSUPPORTED_IMAGE` citando os quadros), com os fakes de `test/support/assets-fakes.ts` (`AssetStorageFake` — escreve `put` e `remove:<chave>` —, `ImageProcessorFake` com `result`/`refusal`/`resizes` (as `NormalizeOptions` pedidas), `ImageFetcherFake` com `answer`/`refusal`, `AssetsDaoFake`) num diário comum que prova `normalize → put → insert`.

- `server/test/integration/assets-dao.spec.ts`: colunas gravadas, `findManyInCampaign` filtrando a outra mesa, **mesa B não vê o asset da mesa A**, dono apagado → `owner_id` nulo, mesa apagada apaga os assets, `storage_key` repetida → `23505`. Fábricas em `server/test/support/assets-factories.ts` (`newAssetPo`, `lyraPortraitPo`).

- `server/test/infrastructure/asset-storage/create-bucket-input.spec.ts` (unit): `us-east-1` → só `{ Bucket }`, sem `CreateBucketConfiguration`; `sa-east-1` → `LocationConstraint: 'sa-east-1'`.
