# Fichas — servidor

Hub: [`../sheets.md`](../sheets.md). Módulo `server/src/modules/sheets/`. Contratos em [`contratos.md`](contratos.md).

## Tabelas

- `sheet_templates` (`0072_sheet_templates`, `sheet-templates.po.ts`): `id`, `campaign_id` (cascade), `folder_id` nulo = raiz, `name` (`CHECK` 1–60), `html`, `css`, `js`, `version` (≥ 0, começa em 0), `created_by` (→ `users`, set null), timestamps. Único `(campaign_id, id)`, índice `(campaign_id, folder_id)`. FK composta `sheet_templates_folder_fk` (`campaign_id`, `folder_id`) → `scene_folders` **editada à mão** para `ON DELETE SET NULL ("folder_id")` (a armadilha da `0033`, ver [`../library.md`](../library.md)).
- `token_sheets` (`0073_token_sheets` + `0074_sheets_in_library`, `sheets.po.ts`): `id`, `campaign_id` (cascade), `template_id`, `name` (`CHECK` `token_sheets_name_length` 1–60), `folder_id` nulo = raiz, `token_id` **nulo** = sem token (→ `tokens`, **set null**: apagar o token deixa a ficha na biblioteca, sem dono), `visibility` (enum `sheet_visibility`: `controllers` padrão | `table`), `values` JSONB (`{}`), `version` (≥ 0), timestamps. **Várias fichas por token** (sem índice único em `token_id`). Índices `(campaign_id, template_id)` (a contagem "em uso"), `(campaign_id, token_id)` e `(campaign_id, folder_id)`. FK composta `token_sheets_template_fk` → `sheet_templates` **restrict**; FK composta `token_sheets_folder_fk` → `scene_folders` **editada à mão** para `ON DELETE SET NULL ("folder_id")`.
- `0074` (gerada e editada à mão): `name` entra nulo, é preenchido com o nome do modelo (`UPDATE … FROM sheet_templates`) e só então vira `NOT NULL`; a FK de `token_id` troca cascade por set null.
- `sheet_actions`: recibos por `(campaign_id, user_id, action_id)`, como `library_document_actions` (operação, SHA-256 canônico do pedido pelo `commandFingerprint` do documents, recibo sem valores).
- `token_sheets.character_id` (`0075_characters`): a ficha do personagem (FK composta set null, `CHECK token_sheets_one_holder`); a migração moveu para lá as fichas das âncoras, e desde a Fase 9 é onde toda ficha de jogador nasce. `characters.main_sheet_id` aponta a principal. Ver [`../characters/fichas.md`](../characters/fichas.md).
- Exportadas no `schema.ts`; `truncateAllTables` inclui as três. O `values` é tipado no PO por `SheetValuesPo` (o JSON que o orçamento do contrato deixou entrar), para o PO não importar DTO.

## Modelos

- `SheetTemplateBo(access)`: `requireAuthor` (só mestre, co-mestre incluso; espectador e jogador → `FORBIDDEN`), `requireVersion` (→ `SHEET_TEMPLATE_VERSION_CONFLICT` "version N; expected M"), `requireUnused(template, n)` (→ `SHEET_TEMPLATE_IN_USE` "is used by N sheets; expected none"; conta **todas** as fichas, com ou sem dono), `requireFolder` (→ `FOLDER_NOT_FOUND`).
- `SheetTemplatesService` (`get`, `create`, `update`, `delete`): `memberAccessOf` → `requireAuthor` **antes** de qualquer trava → transação com `CampaignsDao.lockById` → trabalho → commit → `library:changed`. Recusa não publica. Toda gravação soma a versão; `delete` conta as fichas (`SheetsDao.countOfTemplate`) dentro da trava.
- Biblioteca: `LibraryService.deleteFolder` chama `SheetTemplatesDao.moveFromFolder` **e** `SheetsDao.moveFromFolder` (sobem ao pai na mesma transação, **sem** somar a versão). O agregado `GET /campaigns/:id/library` (`LibraryImageService.list`) leva `sheetTemplates` (resumo, sem código) **só ao mestre** e `sheets` (resumos, ver abaixo).

## Fichas na biblioteca

- **Dono** (`holder`): ninguém, um token solto ou um **personagem** (`token_sheets.character_id`, Fase 9 do plano do personagem; detalhe em [`../characters/fichas.md`](../characters/fichas.md)). `{ memberId }` = o personagem do jogador; `{ tokenId }` de um token ligado = o personagem dele; de um solto = o token. Nada é criado (a âncora do elenco não nasce mais por ficha).
- `SheetHolderService` (`sheet-holder.service.ts`, sem deps): `resolve(daos, campaignId, holder)` → `SheetHolderPlacePo | null` (`{ token } | { character }`), `placeOfSheet(daos, sheet)`, `sheetsOf(daos, campaignId, place)`; `characterPlaceIn` → `CHARACTER_NOT_FOUND`. Regras no `SheetItemBo`: `requireGridToken` (outra mesa ou elenco → `TOKEN_NOT_FOUND`), `requirePlayerCharacter` (personagem que a mesa vê; mestre sem personagem, espectador, estranho → `MEMBER_NOT_FOUND`).
- `SheetItemBo(campaignId)`: `requireFolder` (→ `FOLDER_NOT_FOUND`), `requireGridToken`, `requirePlayerCharacter`, `requireHolder` (→ `{ tokenId } | { characterId }`; sem dono → `SHEET_HAS_NO_TOKEN` "Sheet X has no holder; expected a sheet held by a token or a character"), `mainSheetWritesOf` (a regra da ficha principal).
- `SheetsDao`: `find`, `listOfToken`, `listOfCharacter` (ordem de criação), `listOfCampaign`, `countOfTemplate`, `insert`, `patchValues`, `update` (`SheetChangesPo`: `name`, `folderId`, `tokenId`, `characterId`, `visibility`, `templateId` + versão), `delete`, `moveFromFolder`, `placeOf`/`placesOf` (`TokenPlacePo`: token, `characterId` do token, cena, `kind`, visibilidade, é o grid do grupo, controladores; duas consultas para qualquer número de tokens), `characterPlacesOf`/`characterPlaceOfUser` (`CharacterPlacePo`, pelo `CharactersDao` no mesmo executor), `holdersOf(mesa, fichas)` (`SheetPlacesPo { tokens, characters }`), `action`, `recordAction`. Não lê mais `member_cards`.
- `SheetAccessBo(access, { sheetId, visibility, holder })` (por `toSheetAccessBo(access, sheet, place | null)`): `holder` = `{ token: TokenControl, seen }` (grid pelo `SceneAccessBo.canSee`) ou `{ character: CharacterSeat }` (visto e controlado pelo `CharacterBo`: personagem guardado → só mestres) ou `null` (**sem dono** → só mestres leem, escrevem e gerenciam). `canRead` = vê o dono **e** (controla, ou `table`); `canEdit` = lê e controla; `canManage` = lê e é mestre. Ilegível → `SHEET_NOT_FOUND` (nunca 403); legível sem edição → `FORBIDDEN` ("control of its holder").
- `SheetsService` (`get`, `listOfToken`, `listOfCharacter`, `create`, `updateValues`, `update`, `delete`; deps `read`, `transaction`, `snapshot`, `clock`, `publisher` (`sheet:changed`), `library` (`library:changed`), `characterPublisher` (`character:changed`), `holders`): escrita trava a **mesa** (`lockById`). Recibo idempotente: mesmo `actionId` + mesmo pedido devolve o recibo com o estado atual e reautoriza (sem publicar nem mexer na principal de novo); pedido diferente → `SHEET_ACTION_REUSED`.
- **Ficha principal**: `create`, `update` com `holder` e `delete` chamam `keepMainSheet` (`main-sheet-writes.ts`) na mesma transação: primeira ficha de um personagem → `main_sheet_id`; a principal que sai → `null`; trava os personagens (a mesma linha de `campaigns`, já travada) e soma a versão deles só se algo mudou.
- `listOfToken`: token ligado → as fichas do personagem; `listOfCharacter`: personagem de outra mesa ou que o leitor não vê → `CHARACTER_NOT_FOUND`.
- Valores: `patchValues` é um `UPDATE` só, `values = (values || set) - removed::text[]`, versão + 1. O resultado é conferido de novo com `sheetValuesDto`; estourou → `ZodError` → 400 e a transação desfaz.
- **Publicações** (depois do commit, nessa ordem): `sheet:changed { campaignId, sheetId, version, at }` (sem valores) a cada escrita aplicada; `library:changed` em criar, renomear, mover, trocar dono, visibilidade, modelo e excluir; `character:changed` dos personagens cuja principal mudou. **Valores só `sheet:changed`.** Porta `SheetPublisherPort`, adaptador `SocketIoSheetPublisher` (`RealtimeOutlets.sheetPublisher`); `RealtimeOutlets.characterPublisher` é o mesmo `SocketIoCharacterPublisher` dos comandos do board (`build-app.ts`).
- Agregado: `LibraryImageService.list` lê `SheetsDao.listOfCampaign` + `holdersOf` e filtra por `readableSheetSummaries` (mestre todas; jogador e espectador as que leem; ninguém lê uma sem dono); as pastas delas entram nos ancestrais visíveis.

| Rota                                                       | Quem                  | Saída                      | Erros                                                                                  |
| ---------------------------------------------------------- | --------------------- | -------------------------- | -------------------------------------------------------------------------------------- |
| `POST /campaigns/:c/sheet-templates`                       | mestre                | 201 `{ template }`         | 400 · 403 · 404 `FOLDER_NOT_FOUND`                                                     |
| `GET/PATCH /campaigns/:c/sheet-templates/:t`               | mestre                | 200 `{ template }`         | 400 · 403 · 404 `SHEET_TEMPLATE_NOT_FOUND` · 409 `…_VERSION_CONFLICT`                  |
| `DELETE /campaigns/:c/sheet-templates/:t`                  | mestre                | 204                        | 403 · 404 · 409 `SHEET_TEMPLATE_IN_USE` (mensagem cita "N sheets")                     |
| `POST /campaigns/:c/sheets`                                | mestre                | 201 `{ sheet, receipt }`   | 400 · 403 · 404 `TOKEN_`/`MEMBER_`/`FOLDER_`/`SHEET_TEMPLATE_NOT_FOUND` · 409          |

| `GET /campaigns/:c/tokens/:t/sheets`                       | membro                | 200 `{ sheets }` (resumos) | 404 `TOKEN_NOT_FOUND` (outra mesa, elenco, id malformado)                              |
| `GET /campaigns/:c/characters/:ch/sheets`                  | membro                | 200 `{ sheets }` (resumos) | 404 `CHARACTER_NOT_FOUND` (outra mesa, guardado para não mestre, id malformado)        |
| `PATCH /campaigns/:c/sheets/:s/values`                     | mestre ou controlador | 200 `{ sheet, receipt }`   | 400 · 403 · 404 · 409 `SHEET_ACTION_REUSED`                                            |
| `PATCH /campaigns/:c/sheets/:s`                            | mestre                | 200 `{ sheet, receipt }`   | 400 · 403 · 404 `SHEET_`/`TOKEN_`/`MEMBER_`/`FOLDER_`/`SHEET_TEMPLATE_NOT_FOUND` · 409 |

Corpo até 2 MiB. Id malformado na URL = 404. Não membro → 404 `CAMPAIGN_NOT_FOUND`; `MEMBER_NOT_FOUND` responde "Player not found at this table".

## Barras pela ficha

- `sheet:adjustBar` (`sheetAdjustBarCommandDto`, estrito) ligado em `board/sheet-commands.ts` pelo `mutate` do board gateway: `onCommand` + **fila da mesa**, ack `{ ok, version }`. `SHEET_NOT_FOUND` e `SHEET_HAS_NO_TOKEN` ("This sheet is not held by a token") estão no `PUBLIC_MESSAGE` de `board-command-edge.ts`.
- `SheetBarsService.adjustBar` (deps `members`, `sheets`, `holders`, `tokens`, `characters`): lê a ficha no pool, `placeOfSheet`, `requireEdit` (Caio numa `table` → `FORBIDDEN`; ficha da Quelm, ou sem dono para quem não é mestre → `SHEET_NOT_FOUND`), `SheetItemBo.requireHolder` (o mestre numa ficha sem dono → `SHEET_HAS_NO_TOKEN`); personagem → `CharactersService.adjustBar` (`character:changed`, versão dos personagens); token solto → `TokensService.adjustBar` com o grid do token. O `adjustHolderBar` e o caminho da âncora saíram (`tokens.service.ts` ficou com 444 linhas).

## Armadilhas

- O `sheet:changed` do create chega depois da resposta HTTP: um spec que grava em seguida e espera o evento da escrita precisa de `silence()` antes de gravar os eventos, senão lê o do create.
- Apagar um token não publica `library:changed`: a ficha fica sem dono (`set null`) e a biblioteca aberta só vê isso no próximo `library:changed` ou recarga.
- Ficha de personagem sem jogador (quem saiu da mesa) sai no resumo com `tokenId` e `memberId` nulos, como uma sem dono; só mestres a leem. Distinguir pede `characterId` no `sheetSummaryDto` (mudança de contrato, não feita).
