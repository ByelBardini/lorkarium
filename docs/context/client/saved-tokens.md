# Client · tokens salvos

A aba "Tokens salvos" da sala, o "Salvar na minha lista…" do menu do token e o spawn no tabuleiro (clique com a entrada armada ou arrastar da lista até a casa). Server, contrato e planos em [`../saved-tokens.md`](../saved-tokens.md); o tabuleiro em [`board.md`](board.md).

## Conversão e serviço

- `src/lib/token-copy.ts` — `copiedLookOf(token)` (a aparência que uma cópia leva: imagem, borda, inverter, direção, visão, luz, cone, aura, bloqueio, visão mágica; usado também pela colagem, `paste-placement.ts`), `savedTokenBodyOf(token)` (o `TokenDto` como o membro o salva: o que o token mostra — o ligado vira cópia solta —, barras com `display`, formas sem id e `activeForm` pelo índice; nunca casa, controle, véu, combate nem personagem) e `spawnedTokenOf(corpo, casa, newId)` (o `NewTokenInput` do `token:createMany`: `controllerIds: []` — o server põe o jogador no controle —, ids novos nas formas, `activeFormId` da forma do índice).
- `src/services/saved-tokens-api.ts` — `SavedTokensApi` / `HttpSavedTokensApi(transport)` no `AppDependencies` (`savedTokens`): `list`, `create`, `update`, `remove` e as pastas (`listFolders`, `createFolder`, `renameFolder`, `removeFolder`), respostas pelo DTO. Falhas: `limit`, `folder_name_taken`, `folder_limit`, `folder_not_found`, `image_not_found` (`ASSET_NOT_FOUND`), `not_found`, `forbidden`, `invalid`, `unauthenticated`, `rate_limited` com `retryAfterSeconds`, `plan_limit` (o `PlanLimitFailure`), `offline`, `unexpected`.
- `src/stores/saved-tokens-store.ts` — `createSavedTokensStore(api, mesa)`: `savedTokens` (`null` até a 1ª lista), `folders`, `loadFailure`, `load`, `save`, `update`, `remove` e as pastas; cada mudança confirmada entra na lista, e uma lista pedida antes de uma mudança é descartada e pedida de novo (o molde das rolagens salvas). Apagar pasta tira os tokens dela.

## Mira e spawn

- `src/stores/spawn-aim-flow.ts` — `createSpawnAimStore()`: `armed` (o `SavedTokenDto`), `ghost` (`SpawnGhostView`), `arm` (armar o já armado desarma), `disarm`. `sendSpawn(deps, salvo, casa, { readOnly, say })`: um `createTokens` (o mesmo comando e as mesmas regras da colagem), confirmado vai ao desfazer como `tokensAdded` pelo id do server, recusado diz o porquê na linha de status (`tokenCommandFailureMessage`); só leitura não manda nada.
- `src/features/saved-tokens/use-room-spawn.ts` — `useRoomSpawn({ campaignId, api, commands, interaction, edits, scopeOf, sceneOf })` → `{ list, aim, spawnAt(casa), dropAt(id, mundo) }`: uma lista e uma mira por visita; Esc desarma (listener na janela só enquanto armado); `dropAt` acha o salvo na lista e põe centrado no ponto (`dropCellOf`, fora da cena nada).
- Renderer: `spawn-ghost.ts` — `SpawnGhostView = { token: TokenView }` (`spawnGhostOf(corpo)`: o próprio token, id `spawn-preview`, sem pegar, selecionar nem arrastar) e `spawnLandingOf(view, mundo)`. `BoardView.spawnGhost` (entrada `spawnGhost` do `buildBoardView`, ligada pela `board-canvas` à mira); com ele a `pressRouteOf` devolve `spawnPoint` (depois do rascunho da patrulha) e a `PrimaryPress` emite `spawnPointPicked { cell }`; o movimento livre do ponteiro leva a prévia (`pointerMoved(contexto, at)`). `pixi-spawn-ghost.ts` desenha a prévia **com o mesmo corpo dos tokens** (`newTokenSprite` + `drawTokenBody` de `pixi-token-sprite.ts`, extraídos da `pixi-token-layer.ts`) a 55% de opacidade; o corpo só é redesenhado ao trocar de token ou chegar a imagem (`refreshArt`), o movimento só muda a posição. `imageUrlsOf` mantém a imagem da prévia no cache.
- Arrastar para uma pasta: cada pasta e o "Sem pasta" são alvos (`use-folder-drop.ts`, `useFolderDrop(list, folderId, onProblem)`): soltar move o token para ela (`update { folderId }`; já estando lá, nada vai), com o destaque `DROP_TARGET_CLASS` enquanto passa por cima. O `effectAllowed` é `copyMove` (copiar no tabuleiro, mover na lista).
- **Armadilha:** o alvo aceita já no `dragenter`, não só no `dragover` (pastas e tabuleiro). Uma soltura rápida chega antes de qualquer `dragover` no alvo, e o navegador só entrega o `drop` se o último `dragenter`/`dragover` foi cancelado — sem isso, arrastar de uma linha para a vizinha não fazia nada.
- Arrastar: a entrada é `draggable` (com direito de criar) e leva o id em `SAVED_TOKEN_DRAG_TYPE` (`src/lib/saved-token-drag.ts`: `carriesSavedToken`, `savedTokenIdOf`, `dropWorldOf(câmera, origem, cliente)`); a `board-canvas` aceita só esse tipo (`onDragOver`/`onDrop`) e entrega `onSavedTokenDrop(id, mundo)`.
